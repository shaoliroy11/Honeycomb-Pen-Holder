# Honeycomb-Pen-Holder
Honeycomb-style pen holder designed in Autodesk Inventor.

A cylindrical desk pen holder with a hexagonal (honeycomb) perforated wall, designed in Autodesk Inventor. The open mesh keeps it light, looks good, and lets us see how full it is at a glance.
Features:
1. Honeycomb hexagon pattern wrapped around the full cylinder
2. Solid base so pens and pencils stay put
3. Rolled rim at the top for a clean edge and extra stiffness
4. Flared conical base for stability on the desk
5. Fully parametric model, so size and pattern are easy to change
